# Лабораторные работы по C#

Каждую лабораторную размещай в своей папке внутри консольного проекта `LW`. Название папки и файла должно содержать номера работы, например `LW_40-41/LW_40-41.cs`. Файлы с исходными данными храни рядом с кодом. В Visual Studio папка и её содержимое должны быть видны в проекте `LW`.
