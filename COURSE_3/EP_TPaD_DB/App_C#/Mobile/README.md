# Мобильная версия «Территория хоккея»

[Открыть исходный файл](index.html)

## Запуск на телефоне

1. Скачайте `Mobile/index.html` на Android или iPhone.
2. Откройте сохранённый HTML-файл в браузере (Chrome, Safari или совместимом).
3. Интернет не требуется: интерфейс, SVG-графика, стили и JavaScript находятся в одном файле.

Это **не APK и не IPA**: исходная версия `App` использует Windows Forms
(`net10.0-windows`) и не запускается напрямую на Android и iOS.
Файл `Mobile/index.html` — самостоятельная адаптивная браузерная
демонстрация общего интерфейса, **не полный порт WinForms**.

## Что реализовано

- Адаптация для портретной и альбомной ориентации, сенсорные кнопки.
- Мобильная хоккейная сцена, навигация, меню и разделы.
- Локальный демонстрационный вход с полем кода, анимацией фамилии на майке.
- Демонстрационная регистрация, профиль, расписание, аренда, информация.
- Синхронное заледенение кнопок и лёгкий снег, без дорогого Canvas-рендера.
- Уважение системной настройки «Уменьшить движение» / Reduced Motion.
- Офлайн-работа без внешних библиотек и сетевых запросов.
- Только логин (при включённом флажке) сохраняется в localStorage.
  Пароль и код не сохраняются и не отправляются.

## Ограничения

Действующая серверная авторизация, отправка электронных писем,
реальное расписание, бронирования и база данных отсутствуют.
Отдельные изображения настольной версии заменены компактной
векторной сценой. Браузерный рендер следует проверить на реальных
устройствах: автоматическая проверка JavaScript-синтаксиса не равна
тестированию в iOS Safari или Android Chrome.

Для нативных установочных файлов потребуются отдельные сборки:
Android APK/AAB и iOS IPA (для последней также нужны средства Apple).
