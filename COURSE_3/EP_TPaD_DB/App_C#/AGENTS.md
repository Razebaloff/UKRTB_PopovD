# Правила оформления приложения «Территория хоккея»

Постоянные требования пользователя к последующим изменениям этого приложения:

- Не добавлять пунктирные, прерывистые или точечные линии по краям полей ввода и кнопок.
  Запрет действует во всех состояниях: обычном, при наведении, нажатии и фокусе с клавиатуры.
- Не использовать стандартный Windows focus rectangle и не имитировать его строчкой или швом.
  Кнопки обозначают фокус изменением тона, текстовые поля — кареткой.
- По последнему указанию пользователя возвращён вариант входа и регистрации с овальными
  тканевыми вставками в тон майки. Сохранять этот вариант; надписи без вставок отменены.
- Сохранять реальные элементы ввода, редактирование, Tab и маскировку пароля.
- При нажатии кнопки сначала полностью завершаются оборот клюшек и волна, затем выполняется действие
  и начинается переход. Эффект не захватывает флаги и не рисуется неподвижным слоем поверх камеры.
- Все файлы приложения сохранять в COURSE_3/EP_TPaD_DB/App_C# этого репозитория.
- Слева сохранять порядок: Салават Юлаев, Толпар, Агидель, Астра, школа Азаматова.
  Использовать реальные исходные эмблемы, сохранять цвета и пропорции, без круглых подложек.
- Вход двухэтапный: «ПРИСЛАТЬ КОД» → поле кода и «ВОЙТИ» → снежная сцена → главное меню.
  Пока это явно обозначенная демонстрация с любым непустым кодом, без отправки писем.
  Изменение логина/пароля сбрасывает запрос кода.
- «Запомнить меня» хранит только логин и флажок. Введённые пользователем пароль и код не сохранять в файлах,
  превью или журналах. Статический экспорт всегда показывает пустые поля.
- Не выполнять растеризацию льда/ткани или масштабирование больших исходников клюшек на каждом кадре.
  Сначала готовить фон и небольшие слои, затем запускать отсчёт анимации.
