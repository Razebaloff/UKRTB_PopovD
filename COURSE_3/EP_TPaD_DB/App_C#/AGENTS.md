# Правила оформления приложения «Территория хоккея»

Постоянные требования пользователя к последующим изменениям этого приложения:

- Не добавлять пунктирные, прерывистые или точечные линии по краям полей ввода и кнопок.
  Запрет действует во всех состояниях: обычном, при наведении, нажатии и фокусе с клавиатуры.
- Не использовать стандартный Windows focus rectangle и не имитировать его строчкой или швом.
  Кнопки обозначают фокус изменением тона, текстовые поля — кареткой.
- По последнему указанию пользователя возвращён вариант входа и регистрации с овальными
  тканевыми вставками в тон майки. Сохранять этот вариант; надписи без вставок отменены.
- Сохранять реальные элементы ввода, редактирование, Tab и маскировку пароля.
- При нажатии кнопки сначала полностью завершаются оборот клюшек и волна, затем выполняется действие
  и начинается переход. Эффект не захватывает флаги и не рисуется неподвижным слоем поверх камеры.
- Все файлы приложения сохранять в COURSE_3/EP_TPaD_DB/App_C# этого репозитория.
- Слева (слева направо) сохранять обратный порядок: школа Азаматова, Астра, Агидель, Толпар, Салават Юлаев.
  Использовать реальные исходные эмблемы, сохранять цвета и пропорции, без круглых подложек.
- Вход двухэтапный: «ПРИСЛАТЬ КОД НА ЭЛ. ПОЧТУ» → поле кода и «ВОЙТИ» → снежная сцена → главное меню.
  Пока это явно обозначенная демонстрация с любым непустым кодом, без отправки писем.
  Изменение логина/пароля сбрасывает запрос кода.
- «Запомнить меня» хранит только логин и флажок. Введённые пользователем пароль и код не сохранять в файлах,
  превью или журналах. Статический экспорт всегда показывает пустые поля.
- Не выполнять растеризацию льда/ткани или масштабирование больших исходников клюшек на каждом кадре.
  Сначала готовить фон и небольшие слои, затем запускать отсчёт анимации.
- Штатная отмена подготовки кадров при изменении размера или закрытии окна должна завершаться
  без throw. Возвращать пустой результат старого кэша и игнорировать его в окне;
  реальные ошибки отрисовки сохранять для обработки вызывающим кодом.
- При неизменном масштабе переиспользовать шрифт контрола. Не освобождать прежний Font
  после назначения равнозначного нового: WinForms может сохранить старый экземпляр в свойстве.

- Вход: центрировать флажок «ЗАПОМНИТЬ МЕНЯ» вместе с надписью на майке по горизонтали, сохраняя Y.
- На финальном этапе входа фрагменты полей физически разлетаются к нижним углам вместе со снежинками,
  снежная метель приходит из двух верхних углов. Имя заметно растёт при нанесении на майку,
  световые лучи расходятся по всему экрану. Следить за скоростью рендера, не пересоздавать фон на каждом кадре.
- Шрифт интерфейса возвращён к исходному Arial на всех экранах; длинная кнопка с кодом не должна обрезаться.
- При наведении мышью на каждую кнопку (шайбы, кнопки меню и овальные кнопки входа)
  слой инея плавно нарастает от края к центру, а при уходе курсора плавно исчезает.
  Узоры ледяных кристаллов кэшируются по размеру элемента и не пересоздаются на каждом кадре.
- При вращении клюшек используется не отдельное облако снежинок, а многослойная метель:
  пересекающиеся турбулентные струи, снежная пыль, длинные шлейфы и кристаллы.
  Все эффекты ограничены свободным промежутком между флагами, флаги не затрагиваются.
