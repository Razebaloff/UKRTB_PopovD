# «ТЕРРИТОРИЯ ХОККЕЯ» — приложение учебной практики

Windows Forms, C# / .NET 10. Все изменения приложения сохраняются в
`COURSE_3/EP_TPaD_DB/App_C#`.

![Стартовый экран](Entry_Preview.png)

## Стартовый экран

Слева — «ВОЙТИ», справа — «ЗАРЕГИСТРИРОВАТЬСЯ», снизу по центру — «РАСПИСАНИЕ».
Белые подписи максимально вписаны в ширину чёрных шайб; длинная подпись остаётся
в одну строку. Круглые шайбы имеют матовую зернистую поверхность резины, мелкие поры,
небольшие сколы кромки, потёртые участки и надрезы от лезвий с тёмным каналом
и подсвеченной гранью. У каждой шайбы свой постоянный рисунок износа.
Добавлены мягкие тени и рассеянный отблеск. Светлого пунктирного кольца нет.
Надписи используют чуть более угловатый и плотный Arial Bold.

Над заголовком расположена одна строка с общей осью по центрам эмблем и флагов.
Порядок слева направо:

**Салават Юлаев · Толпар · Агидель · Астра · школа имени М. М. Азаматова ·
флаг Башкортостана · клюшки · флаг России · ЦСКА · СКА · Спартак · Авангард · Ак Барс.**

Эмблемы загружены из источников клубов и хоккейных организаций, не перерисованы.
Цвета и пропорции сохранены. Эмблемы показаны без подложек и круглых масок;
прозрачные поля обрезаются, сами изображения центрируются на общей горизонтали.
У «Астры» и школы Азаматова удаляется только внешний светлый фон,
связанный с краями исходного изображения; белые детали внутри эмблем сохраняются.
Разный DPI исходников не влияет на размер: загрузка и отрисовка используют пиксели.
Вместо прежней рисованной схемы использована фотография настоящей клюшки
с прозрачным фоном: две зеркальные копии пересекаются нижними перьями.
Изображения встроены в приложение, поэтому интернет при запуске не требуется.
Источники, размеры и сведения об использовании перечислены в [ASSETS.md](ASSETS.md).

Кнопки сохраняют поведение учебного прототипа: открывают существующее главное меню;
«РАСПИСАНИЕ» устанавливает фокус на «РАСПИСАНИЕ ЗАНЯТИЙ».
Авторизация, регистрация, загрузка расписания и подключение БД пока не реализованы.

## Изображения и качество

| Файл | Размер | Формат |
|---|---|---|
| Entry_Preview.png, Menu_Preview.png | 1920 × 1080 | PNG без потерь |

PNG-превью сохраняют пиксели отрисованной сцены без JPEG-артефактов вокруг букв,
линий и эмблем. JPEG небольших превью оставлены для совместимости.
Экспорт PNG до 15360 × 8640 доступен из приложения командами ниже;
крупные экспортированные изображения не нужны для запуска и не включены в репозиторий.
В приложении используется новый фон `App/Assets/IceFrame.png`.
Сцена и кнопки рисуются в фактическом разрешении окна и копируются из кэша 1:1.
Убрано промежуточное увеличение вдвое с последующим уменьшением:
фон, эмблемы и надписи больше не проходят повторную фильтрацию.
Контуры сглаживаются при отрисовке; текстура резины, сколы и надрезы строятся
непосредственно в целевом разрешении.

Фон заново создан встроенным ImageGen: более чистая поверхность льда, чёткие
следы лезвий и сапфировая кристаллическая рамка. Синяя палитра немного темнее
прежней; средние тона дополнительно откалиброваны при отрисовке.
Цвета эмблем не изменены. Изображение сохранено без потерь.
**Его исходный размер — 1672 × 941, а часть эмблем имеет 150–200 пикселей.**
Контуры букв, шайб, флагов и разметки отрисовываются непосредственно в целевом
разрешении, а растровые изображения масштабируются. Поэтому экспорт 16К
не означает, что каждая деталь фона и каждая эмблема имеют нативное разрешение 16К.

Изображения получены общей отрисовкой приложения. Это экспорт сцены,
а не снимок окна Windows. В Linux используется замена Arial;
в Windows форма букв может немного отличаться.

## Запуск в Visual Studio

1. В GitHub Desktop нажать **Fetch origin → Pull origin**.
2. Открыть [App/LP_PopovD_App.slnx](App/LP_PopovD_App.slnx) в Visual Studio 2026.
3. Установить .NET 10 и рабочую нагрузку **«Разработка классических приложений .NET»**.
4. Нажать **F5**.

F11 — переключение полного экрана и окна, Esc — выход, Tab — выбор кнопки,
Enter / пробел — нажатие.

Повторный экспорт PNG без потерь из папки `App`:

```powershell
dotnet run -c Release -- --export-entry ..\Entry_16K.png 15360
dotnet run -c Release -- --export-menu ..\Menu_16K.png 15360
```

Ширина задаётся от 960 до 15360 пикселей; высота вычисляется для соотношения 16:9.
Расширение `.png` выбирает PNG без потерь, `.jpg` — JPEG с качеством 100.
Экспорт в 16К использует плитки, итоговый буфер занимает около 380 МиБ.
Окно не загружает файлы 16К как фон, а рисует интерфейс под текущий экран.

## Проверка

Release-сборка для Windows проверена с `EnableWindowsTargeting=true`:
**0 ошибок, 0 предупреждений**. Общая отрисовка проверена
в 960 × 600, 1600 × 900 и 1920 × 1080.
Проверены загрузка всех 12 изображений, сохранение исходных пикселей при разном DPI,
границы десяти эмблем, прозрачность внешних фонов и сохранение белых деталей логотипов.
Окно WinForms в Windows в этой среде не запускалось.
