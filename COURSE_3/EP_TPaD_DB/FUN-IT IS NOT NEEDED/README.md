# Стражи рассвета / Verdant Guard

Завершённая небольшая одиночная tower defense на **C# / Windows Forms / .NET 8** с оригинальными картами, персонажами, процедурной графикой и синтезированным звуком. Бои, меню, развитие, поражение, повторное прохождение и финал кампании реализованы. Игра работает офлайн, без покупок, аккаунтов и сторонних игровых движков.

Это самостоятельная игра с общими механиками жанра. Она **не является полной копией Kingdom Rush Origins**, не использует её исходный код, название, карты, тексты, персонажей, музыку или изображения. Объём и художественная проработка отличаются от коммерческой игры.

## Запустить готовую игру

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте весь архив.
2. Откройте папку `игра` и дважды нажмите **Start-Game.cmd** либо **Ready/VerdantGuard.exe**.
3. Требуется **Windows 10/11 x64** и **.NET Desktop Runtime 8 x64 или более новая совместимая основная версия**. Готовая сборка разрешает переход к установленной более новой версии Desktop Runtime. Если среда отсутствует, загрузчик Windows предложит её установить. Все файлы из `Ready` необходимо держать вместе.
4. Нажмите «Начать кампанию», выберите героя, затем «Защитить рубеж». Постройте башни и нажмите Enter.

Готовая сборка зависит от установленной среды .NET. Для создания отдельного EXE со встроенной средой используйте публикацию ниже.

## Открыть в Visual Studio

1. В Visual Studio Installer установите нагрузку **«Разработка классических приложений .NET»** и SDK .NET 8. Подходит Visual Studio с поддержкой .NET 8, включая более новую установленную версию.
2. Откройте **Стражи_рассвета.sln**.
3. Нажмите правой кнопкой по **Verdant.Game → Назначить запускаемым проектом**.
4. Нажмите **Ctrl+F5**. Дополнительных пакетов из NuGet в проекте нет.

## Правила и управление

| Действие | Управление |
|---|---|
| Выбрать площадку, построить или улучшить | ЛКМ по площадке, затем кнопки справа |
| Быстрая постройка | 1–4 после выбора площадки |
| Выбрать героя | ЛКМ по герою, кнопка героя или H |
| Переместить героя | После выбора — ЛКМ по дороге |
| Точка сбора стражи | Выбрать казарму → «Указать точку сбора» → дорога в её радиусе |
| Метеор / мороз / подкрепление | Q / W / E, затем ЛКМ по цели |
| Умение героя | R, действует от позиции героя |
| Отмена выбора | ПКМ; Esc отменяет активный приказ |
| Вызвать волну | Enter или кнопка справа, доступна после выхода всех врагов предыдущей волны |
| Пауза | Пробел, P, Esc без активного приказа, кнопка паузы |
| Скорость | Tab или ×1/×2 |
| Полный экран | F11 |
| Эффекты | M; музыка отдельно в настройках |

Обычный пропущенный враг отнимает одну жизнь; пропуск босса отнимает 20. Стража не задерживает летающих врагов. По воздуху стреляют следопыты, руны и герои дальнего боя. Яд, огонь и метеор наносят чистый урон. Продажа возвращает 70% всех затрат на башню.

В кампании 18–20 оставшихся жизней дают 3 звезды, 10–17 — 2, 1–9 — 1. Следующий рубеж открывается после любой победы. Три звезды открывают испытания на этой карте: **героическое** — шесть усиленных волн с одной жизнью; **железное** — одна длинная волна с одной жизнью, только руны и стража. Испытания дают по одной дополнительной звезде. Бесконечный режим доступен на каждой открытой карте и постепенно усиливает здоровье врагов.

Ранний вызов даёт бонус золота, но не убирает оставшихся врагов. Без раннего вызова новая волна приходит автоматически через 16 секунд после завершения появления предыдущей. Первая волна всегда запускается вручную.

## Сохранения

Профиль хранится в `%LOCALAPPDATA%\VerdantGuard\profile.json`. Сохраняются звёзды, улучшения, выбранный герой, сложность, звук, суммарная статистика и рекорд бесконечного режима. Сохранение выполняется после результата боя, выхода на карту и изменения настроек. Есть резервная копия `.bak`, запись через временный файл и проверка диапазонов значений. Активный бой после закрытия приложения начинается заново.

## Проверки и публикация

Из терминала в папке `игра`:

```powershell
dotnet build Стражи_рассвета.sln -c Release
dotnet run --project Verdant.Checks -c Release
dotnet run --project Verdant.Game -c Release
```

Проверки логики работают и на Linux/macOS с SDK .NET 8. Окно игры и аудиовывод предназначены для Windows.

Для Windows x64 EXE со встроенной .NET-средой выполните **Publish-Windows.ps1** в PowerShell либо в Visual Studio: **Verdant.Game → Опубликовать → Папка → win-x64 → автономное развёртывание**. Скрипт сначала выполняет проверки, затем создаёт `publish/VerdantGuard.exe`:

```powershell
dotnet publish Verdant.Game -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Первое восстановление Windows targeting pack или автономной среды может потребовать интернет. Сама игра интернет не использует. Полная справка о выполненной проверке находится в `VALIDATION.md`.

`Build-Ready.ps1` пересобирает обычную готовую сборку в `Ready`, предварительно выполняя те же проверки. После изменения исходников запустите этот скрипт, чтобы готовый EXE соответствовал новому коду.
