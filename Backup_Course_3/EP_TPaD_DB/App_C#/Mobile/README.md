# Мобильная версия с оригинальной графикой Windows-приложения

## Визуальное соответствие

Мобильная версия использует **оригинальные изображения экранов**,
полученные из корня проекта `App_C#`, а не другую тему оформления:

- `Entry_Preview.jpg` — входной экран с клубами, флагами, клюшками и тремя шайбами;
- `Login_Preview.png` — майка и два поля авторизации;
- `Login_Code_Preview.png` — майка и три поля, включая код;
- `Registration_Preview.png` — майка и регистрация;
- `Menu_Preview.jpg` — хоккейная арена с четырьмя кнопками.

Все изображения остаются оригинальными. Поверх них размещаются **невидимые
сенсорные области** в тех же местах, где расположены кнопки десктопного
приложения. Нативные текстовые поля встраиваются в оригинальные формы.

## Оптимизация для смартфонов

- Исходные пропорции десктопных экранов 1920×1080 сохраняются.
- В альбомной ориентации вся сцена помещается на экране.
- В портретной ориентации сцена масштабируется до удобных для касания
  кнопок, доступен горизонтальный свайп и кнопки прокрутки.
- «Обзор» уменьшает сцену целиком, «Масштаб» возвращает крупные элементы.
- Используется одна активная фотография экрана; остальные загружаются
  только при переходе на соответствующую страницу.
- Анимация инея использует CSS и синхронные циклы вместо постоянного
  рисования сложных кристаллов на Canvas.
- Снежный эффект создаёт небольшое число композиционных элементов
  только при успешном демонстрационном входе; при Reduced Motion
  он отключается.
- Учтены сенсорное управление, системные безопасные отступы, масштаб
  экрана, альбомная/портретная ориентация и сохранение только логина.

## Запуск

Скачать `Mobile/index.html` и открыть в браузере Android или iOS.
**Для загрузки исходных изображений нужен интернет**: они берутся из
публичного GitHub-репозитория. Поэтому эта версия не гарантирует
полноценную автономную работу без подключения. HTML не отправляет данные
авторизации и не сохраняет пароль или код.

Это браузерный мобильный интерфейс, **не APK/IPA и не точный порт логики
Windows Forms**. Демонстрационные экраны и расположение элементов
совпадают с десктопными превью; сложные анимации и реальные серверные
функции не воспроизведены один в один.

**Исходная папка `App/` не изменяется.** Вся мобильная разработка
находится отдельно, в `Mobile/`.

## Дальнейшее улучшение

Для полной автономности исходные изображения нужно разместить рядом с
HTML в `Mobile/assets/` и заменить ссылки на локальные пути. Также
можно создать оболочку Android (APK) и iOS (IPA) с WebView; это отдельные
мобильные сборки, а не переименование HTML.
